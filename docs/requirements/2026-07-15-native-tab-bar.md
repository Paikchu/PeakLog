# 原生底部 Tab Bar 需求

## 目标

- 将当前自绘 `HomeDockBar` 替换为 SwiftUI 原生 `TabView` 底部栏。
- 底部栏由系统贴合 Home Indicator 安全区，不再保留额外的人工底部间距。
- 三个入口显示系统图标与本地化文字：日历、计划、设置。
- iOS 26 的材质、选中态、点击反馈与无障碍行为由系统 Tab Bar 管理。

## 交互与状态

- 默认选中计划页。
- 切换 Tab 继续更新 `selectedTab`，不改变三个页面的业务依赖。
- 有可执行计划或最小化训练时，`TrainingActionLayer` 显示在原生 Tab Bar 上方。
- 进入训练专注态时隐藏原生 Tab Bar，由 `TrainingFocusBar` 占据底部操作位置。
- 训练专注态的“完成当前组 / 完成训练”使用纯色胶囊，不显示系统 Glass 边缘或空附件底层。
- 从其他 Tab 恢复训练时，先回到计划页，再恢复训练专注态。

## 不做范围

- 不修改训练计划、训练持久化、历史记录或设置页业务逻辑。
- 不定制系统 Tab Bar 的玻璃背景、圆角、阴影或选中胶囊。
- 不引入新的 ViewModel、导航路由或 Supabase 变更。

## 验收标准

- 底部展示带文字的日历、计划、设置三个原生 Tab。
- 自绘 `HomeDockBar` 不再参与根页面布局。
- 根页面不再添加 `8pt` Dock 底部间距。
- 训练操作层仍位于底部导航上方。
- 训练专注态隐藏 Tab Bar，并继续显示 `TrainingFocusBar`。
- 专注态底部按钮下方没有灰色附件胶囊，按钮点击与休息倒计时仍可用。
- 相关源代码契约测试通过，iOS 26 Simulator 构建通过。
