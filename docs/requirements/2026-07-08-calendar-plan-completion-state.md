# Calendar 今日计划误完成修复需求

- 今日计划的目标组不等于已完成训练。
- Calendar 只能把真实训练记录计入当天完成。
- 计划组的完成态必须有对应的训练记录 set 支撑。
- 云端或本地缓存里只有 `completedAt` / `linkedExerciseSetId`，但找不到训练记录 set 时，应按未完成处理。
- 今日训练页未开始时，计划组应保持空心未完成态。
- 已正常完成并落库的计划组，Calendar 和今日训练页继续显示完成。
- 删除训练记录后，计划完成链接继续回退为未完成。
- 验收：新增今日计划后 Calendar 不显示“当天完成”。
- 验收：完成计划组并落库后 Calendar 显示已完成组数。
- 验收：脏云端状态拉取后不会把未训练计划标记为完成。
