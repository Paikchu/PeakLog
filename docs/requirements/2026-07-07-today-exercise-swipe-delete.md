# 今日动作滑动删除

## 背景

今日页的每日计划动作只能加组/减组，无法删除整个动作；已完成的动作更是没有任何删除入口。

## 需求

1. 今日页每个动作组件支持**由右向左滑动**，在该条右侧露出红色删除按钮（iOS 原生风格）；**只有点击删除按钮才会删除**，滑动本身不触发删除。
2. 删除对象覆盖两类组件：
   - **计划动作**（TodayPlanExercisesSection 中的卡片）：删除该动作及其全部计划组。
   - **记录动作**（无计划时的力量记录卡片）：删除该动作的全部已记录组。
3. **已完成的动作同样支持删除**。删除已完成的计划动作时，其完成组落库产生的训练记录一并级联删除，不留孤儿记录。
4. 训练进行中（专注模式或最小化态）在浏览模式删除计划动作时，进行中的 session 同步剔除该动作；动作被删空则整个训练自动取消。
5. 删除按钮展开期间点击卡片其他区域先收起按钮，避免误触卡片内部的编辑控件。

## 验收方案

- `xcodebuild test`（iPhone 17 Pro Max）全量通过，含新增 `PeakLogTests/TodayExerciseDeleteTests`：
  1. 已完成计划动作删除后，计划与关联记录同时消失；
  2. 记录动作删除后，动作消失，清空的 session 一并移除；
  3. 训练进行中删除动作，live session 同步剔除；删空则训练取消。
- 模拟器手动验证：计划卡片/记录卡片左滑出现删除按钮，点击按钮删除（继续滑到底不会误删，只有橡皮筋回弹）；纵向滚动不受影响。
