# 需求文档: 移除后端依赖并迁移到端侧大模型

## 1. 需求背景
当前用户的健身助手(PeakLog)后端基于 Supabase Edge Functions 实现。为了更好保护用户隐私、提升离线可用性、以及减少服务端开销，需要移除所有后端依赖，将AI功能及数据存储完全迁移到 iOS 本地端侧。由于无需与服务端同步数据，同时需移除所有登录和身份验证相关功能。

## 2. 需求详情
- **完全本地化**：所有健身计划生成、数据记录和偏好修改均需在 iOS 设备本地运行。
- **移除认证模块**：移除应用内所有涉及用户登录、鉴权（Supabase Auth）的功能模块及界面。
- **本地Agent能力**：引入端侧大模型运行框架（如 MLX Swift ），实现基于自然语言交互的健身助手 Agent，它需具备理解用户指示并调用本地方法（Tool Calling）来更新数据状态的能力，进而实现原有的对话式管理体验。

## 3. 验收方案
- [ ] 无网络连接的情况下，应用能正常响应用户的自然语言指令（如生成7日健身计划、记录当次锻炼）。
- [ ] 应用启动时无登录和注册拦截，用户打开即用。
- [ ] 确保在日志中没有任何 Supabase API 相关的网络请求。
- [ ] 在 iOS 17 Pro Max 模拟器等设备上进行测试，模型能顺利加载与推理，资源（内存与电池）占用在接受范围内。
