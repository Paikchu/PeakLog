# 有氧动作与力量动作平级选择

## 目标

- 跑步、骑行、椭圆机和爬楼机作为动作选择器中的普通动作，与力量动作平级。
- 选择阶段不使用独立图标、箭头或跳转；有氧和力量复用同一行、选中状态和底部确认操作。
- 动作类型的差异只体现在确认后的参数配置页。

## 交互范围

- “全部”同时展示力量和有氧动作；“有氧”只展示四种内置有氧动作。
- 有氧行使用主标题、次级“有氧”、右侧选择圆圈和分隔线；力量动作继续显示“器械 · 肌群”。
- 一次选择可混合力量和有氧动作，并按点击顺序进入同一配置页。
- 跑步、骑行配置时长与可选距离；椭圆机、爬楼机只配置时长；力量动作保留现有组数、重量、次数和 RPE 表单。
- 返回选择器保留已选动作与已填参数，已进入配置页的动作不可重复添加。

## 数据与兼容

- 临时选择和配置状态统一；持久化仍为 `strength` 与 `cardio` 两种计划项。
- 不修改 `CardioActivityType` raw value、云端字段、Schema、RLS、Storage、RPC 或 Edge Function。
- 本地化键必须解析为可读中英文名称，不能展示 `cardio.activity.*`。

## 验收

- 四种有氧动作在“全部”和“有氧”中与力量动作采用相同行样式、选择反馈和计数。
- 选择跑步后进入时长、距离参数表单。
- 混合选择按顺序生成草稿；任一参数无效时不保存部分计划项。
- 力量动作搜索、推荐、筛选、自定义和已添加状态不回归。
