# 今日计划动作顺序调整

## 背景
今日计划的动作顺序由创建计划（AI 生成或手动追加）时的顺序决定，用户无法在界面上调整。实际训练时想换个顺序热身/先练大重量动作，只能删除重加，体验很差。

## 目标
1. 今日计划卡片列表支持手动调整动作顺序，改动即时持久化。
2. 交互直观：长按任意动作卡片进入「重排模式」——所有卡片折叠为等高紧凑行（动作名 + 组数 + 拖拽把手），可上下拖拽调整位置，其余行让位动画跟随；点击完成或空白处退出，恢复原卡片展开态。
3. 顺序变更只影响 `TrainingPlanDay.exercises` 数组与 `orderIndex`，不影响任何组的数据或完成状态。

## 范围
- 仅调整**今日**计划的动作顺序（Today 页浏览态）。周计划中其他天、History 页历史记录不在本次范围内。
- 训练进行中（专注模式，含最小化态，即 `activeLiveWorkout` 存在）**不支持**重排——直接禁止进入重排模式。原因：专注模式的训练指针 `PlanLiveWorkoutSession.currentExerciseIndex` 是位置索引，重排会导致指针与 Live Activity 同步失配，成本远大于收益，且专注模式本身不展示可长按的浏览卡片。

## 明确不做
- 不支持跨天拖拽（把动作拖到别的日期）。
- 不做拖到列表边缘自动滚动（v1 折叠行足够矮，一屏可见全部或绝大多数动作）。
- 不改变已有的每组编辑/完成/加组/删组交互，仅新增"长按进入重排"这一入口。

## 验收
- 长按任意动作卡片，列表折叠为紧凑行，可通过拖拽调整任意两个动作的相对顺序，松手后顺序立即生效并持久化（杀进程重开 App 顺序保留）。
- 重排过程中其余行有让位动画；退出重排模式卡片恢复原展开态，组数据/完成状态不变。
- 训练进行中（专注模式或最小化态）无法进入重排模式。
- 重排请求失败（理论上仅并发下今日计划已变化）时顺序回滚并提示错误，与现有错误提示样式一致。
- VoiceOver 用户可通过无障碍动作（上移/下移）达成同样效果，不依赖拖拽手势。
- `tests/plan_exercise_reorder_test.swift` 覆盖重排逻辑；`xcodebuild test` 通过；模拟器手动验证拖拽手感流畅。
