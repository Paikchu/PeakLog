# 历史页周切换记录刷新

- 问题：历史页折叠日历通过左右箭头切换周后，选中日期已变化，但下方已完成训练仍显示切换前日期的数据。
- 影响：用户会把今天训练误认为目标日期训练；截图中 `Aug 2` 下仍出现今天的力量记录。
- 目标：任何会改变 `selectedDate` 的入口，都必须同步刷新力量训练和有氧记录。
- 范围：历史页折叠日历的上一周、下一周切换；点选日期路径保持现状。
- 非目标：不改训练记录创建逻辑，不改历史记录聚合规则，不调整日历视觉样式。
- 验收：先加载 2026-08-09 的卧推记录，再切到 2026-08-02，下方记录必须变成 2026-08-02 的深蹲记录。
- 验收：目标日期没有记录时，不显示切换前日期的训练卡片。
- 验收：`tests/history_calendar_cross_month_selection_test.swift` 覆盖周切换刷新。
