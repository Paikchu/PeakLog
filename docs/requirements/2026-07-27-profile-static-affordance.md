# 个人资料静态元素视觉语义

## 目标

- 在页面顶部与“个人资料”标题之间增加明确留白。
- 让无点击行为的用户资料信息和统计项呈现为静态内容，不再像按钮或入口。
- 保留训练目标、偏好设置和支持入口的现有点击提示与行为。

## 范围

- 用户资料信息移除外层卡片背景、描边和阴影。
- 用户头像移除额外描边。
- 四个统计项移除外层卡片背景、描边和阴影，保留图标徽记、数值和标签。
- PR 静态列表移除外层卡片背景、描边和阴影，保留分组标题与行分隔。
- “个人资料”标题上方增加 16pt 留白，资料信息保持原有区块间距。

## 不做

- 不修改资料、统计或偏好数据。
- 不修改训练目标、偏好、通知和支持入口的交互。
- 不修改 PR 数据、主题颜色或本地化文案。

## 验收标准

- “个人资料”标题上方有 16pt 额外留白，标题与资料信息之间不过度拉开。
- 用户资料信息、统计项和 PR 静态列表没有外层卡片背景、描边或阴影。
- 统计项仍能清晰区分图标、数值和标签。
- 所有真实入口仍可点击并保留右箭头。
- iPhone 17 Pro Max、iOS 26.5 模拟器构建和页面验收通过。
