# 个人资料 A2 紧凑分栏重设计

## 目标

- 采用已确认的 Superdesign A2 方案，压缩信息高度并强化训练总量层级。
- 让无点击行为的用户资料、训练统计和 PR 呈现为静态内容，不再像按钮或入口。
- 保留训练目标、偏好设置和支持入口的现有点击提示与行为。

## 范围

- “个人资料”标题上方保留 16pt 留白；资料信息采用 20pt 水平边距、56pt 头像、20pt 用户名和 14pt 会员信息。
- 训练目标移除分组标题，改为独立可点击入口，保留右箭头并加强目标图标。
- 训练统计合并成单一静态面板：左侧突出总训练量，右侧纵向排列训练次数、连续天数和 PR。
- 统计面板保留背景层级，但不使用描边、阴影、按钮、点击态或嵌套卡片。
- PR 使用上下分隔线与扁平记录行，不使用卡片、图标或右箭头。

## 不做

- 不修改资料、统计或偏好数据。
- 不修改训练目标、偏好、通知和支持入口的交互。
- 不修改 PR 数据、主题颜色、本地化文案或支持入口内容。

## 验收标准

- 页面结构、间距和数据层级与 Superdesign A2 紧凑分栏稿一致。
- 用户资料和 PR 静态列表没有外层卡片背景、描边或阴影。
- 统计面板左侧总训练量为主视觉，右侧三项指标清晰分隔且无点击语义。
- 所有真实入口仍可点击并保留右箭头。
- iPhone 17 Pro Max、iOS 26.5 模拟器构建和页面验收通过。
