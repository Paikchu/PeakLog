# 需求文档：Foundation Models 本地化迁移审计

## 1. 背景
当前 PeakLog 已从原先依赖 Supabase 的后端方案迁移为“计划采用 Apple Foundation Models 端侧能力”的版本。需要对现状做一次审计，确认项目是否已经具备“完全本地化、完全端侧运行、可替代原线上接口”的能力，并通过指定模拟器执行实际测试，输出问题清单，作为后续迁移修复的依据。

## 2. 审计目标
- 评估 App 是否已经完全移除线上接口依赖。
- 评估 App 是否已经实际接入 Apple Foundation Models，并具备原聊天/计划调整/记录写入能力。
- 评估 App 是否具备本地持久化能力，能替代原远端数据库职责。
- 在 `iPhone 17 Pro Max` + `iOS 26.4` 模拟器环境下执行构建与测试验证。
- 将发现的问题、阻塞项、风险项整理到迁移日志中。

## 3. 范围
- `PeakLog` iOS 客户端工程
- 工程配置、依赖、构建脚本、测试配置
- 服务层、ViewModel、对话能力、数据存储能力、语音相关能力
- 迁移文档与日志

## 4. 非目标
- 本次不要求直接完成迁移修复。
- 本次不要求补齐完整 Foundation Models 实现。
- 本次不要求替换 UI 或重构业务流程。

## 5. 验收标准
- [ ] 输出明确结论：当前版本是否能“完全采用本地模型替代所有线上接口”。
- [ ] 输出明确证据：源码级残留依赖、构建结果、测试结果、模拟器验证结果。
- [ ] 输出结构化问题清单，便于后续逐条修复。
- [ ] 问题记录已写入 `docs/logs` 下对应文档。
