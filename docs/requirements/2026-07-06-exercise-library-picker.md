# 动作库与动作选择器（Exercise Library & Picker）

## 背景与问题
- 当前计划/补录中的动作名是自由文本输入（`ExerciseFormCard` 的 TextField），每次手动输入成本高。
- 同一动作多种写法（"Bench Press"/"卧推"/"bench press"）导致历史与 PR 按名字归并不准。
- 健身房场景下用户找动作的心智模型是"按肌群/器械浏览 + 按名字搜索"，现在完全没有支撑。

## 目标
1. 内置一个覆盖齐全的健身房动作种子库（中英双语、含别名、肌群、器械、负重方式），随 App 打包，离线可用。
2. 用户为计划添加动作、或补录训练时，从动作库中**多选**动作，不再手动输入动作名。
3. 保留自定义动作能力：搜索无结果或主动创建，入库后与标准动作同等使用。
4. 让用户在动作库很大的情况下依然能快速命中当天动作（分层漏斗：最近使用 → 肌群筛选 → 搜索）。

## 已确认的决策
- 持久化：方案 A —— 标准库为 App bundle 内只读 JSON（带版本号）；自定义动作存入本地 `LocalAppState`。动作 ID 用稳定 slug，为未来 Supabase 同步预留兼容。
- 交互结构：方案 3 —— 「添加动作」打开的 sheet 第一屏即为 Picker；多选确认后在同一 NavigationStack 内 push 到表单页填组数/重量；表单页的「添加动作」返回 Picker 追加（保留已选）。
- 自定义创建：280 高度小 sheet（与 `ValueEditSheet` 同一语法），仅名称/肌群/负重方式三个字段，创建后自动选中。
- 不做插图；第一版不做拼音/首字母搜索（靠 aliases 覆盖常见简称）。
- 「最近使用」只取实际训练历史（`strengthSessions`），不含仅计划未练的动作。
- 除搜索无结果外，列表底部常驻一个「创建自定义动作」入口。
- 肌群不做彩色编码，保持单一琥珀强调色。

## 交互流程
1. 点「添加动作」→ sheet 打开即 Picker：顶部搜索框（不自动聚焦）、肌群 chips（全部/胸/背/腿/肩/臂/核心/全身）、「最近使用」区（前 8–10 个，按最近度+频次）、「全部动作」按肌群分组（组内按常用度）。
2. 行内容：动作名 + 副信息（器械 · 肌群，最近使用行追加"上次 60kg × 8"摘要）；点击行切换勾选。
3. 选中肌群 chip 后出现二级器械筛选（杠铃/哑铃/器械/绳索/自重/壶铃）。
4. 选中 ≥1 个动作时底部浮现「添加 N 个动作」按钮 → push 表单页，卡片按所选动作预建，`loadType` 已带出（自重动作跳过重量输入）。
5. 搜索匹配中文名、英文名、aliases；无结果时显示「创建自定义动作 "搜索词"」虚线行。
6. 补录（DailyRecordSheet）走完全同构的流程。

## UI 约束（本轮明确）
- **不使用卡片效果**：Picker 列表为通栏平铺，不用 glassPanel/圆角卡片容器包裹分区；层级完全靠字体（字号、字重、颜色）与留白、发丝分隔线表达。
- 字体层级：分区标签 11pt medium `textMuted`；动作名 15pt semibold `textPrimary`；元信息 11pt rounded `textMuted`；数字摘要 rounded design + `accentValue`（数字是主角）。
- 遵循 Graphite 主题：碳黑中性色 + 唯一琥珀强调；选中态、CTA、创建入口均用琥珀表达。
- 动画流畅：全部复用现有三档弹簧曲线，尊重 Reduce Motion（详见技术 plan）。

## 非目标
- 不做动作插图/演示视频。
- 不做 Supabase 同步（仅数据结构预留）。
- 不改动表单页（组数/重量卡片）既有视觉。
- 不做旧数据迁移；旧记录的自由文本动作名原样保留，新增字段全部可选。

## 验收
- 打开 Picker 默认显示「最近使用」（来自训练历史）与按肌群分组的全部动作，无卡片容器。
- 中文名、英文名、别名均可搜到同一动作；如输入 "卧推"、"bench" 均命中杠铃卧推。
- 一次流程内可多选 5 个动作并批量进入表单页，卡片名称与 loadType 与所选一致。
- 搜索无结果时可创建自定义动作，创建后自动为选中态，且下次打开出现在库中。
- 自重动作（如引体向上）选中后表单卡片自动为自重模式。
- 现有本地数据文件（无 customExercises / exerciseId 字段）可正常加载，不丢数据。
- `tests/` 新增逻辑测试全部通过；`xcodebuild test` 通过；iOS 26 iPhone 17 Pro Max 模拟器手动验证选择流与动画。
