# 历史页移除计划详情区需求

## 背景
- 用户希望历史页中日历下方展示的计划详情区整体移除。
- 该区域当前会显示日期、训练标题、动作列表以及“无计划”提示，容易与训练记录回顾产生混淆。

## 需求目标
- 移除历史页日历卡片内与选中日期计划相关的整个详情区。
- 保留日历本身、周/月切换、训练完成记录列表。
- 不新增新的占位说明或替代模块。

## 范围评估
- 本次需求属于 iOS 客户端历史页展示层调整。
- 不修改 `backend`、Supabase Edge Function、agent prompt 或训练计划数据结构。

## 非目标
- 不移除顶部 “Current Plan” 周计划摘要卡片。
- 不修改今日页与聊天页中的计划展示。
- 不修改日历选中逻辑与历史记录聚合逻辑。

## 验收标准
1. 历史页日历区域下方不再出现计划详情内容。
2. 历史页仍可正常切换周/月和选择日期。
3. 训练完成记录列表仍按原逻辑展示。
4. 代码层面存在回归校验，保证 `CalendarGridView` 不再渲染该详情区。
