# 训练记录页移除组完成圆圈需求

## 背景
- 用户反馈历史/训练记录页面中的计划动作列表右侧存在圆圈勾选控件。
- 当前页面职责是回顾和浏览训练记录，右侧勾选控件会让界面看起来像仍然支持在该页面直接完成动作，造成视觉噪音和交互预期偏差。

## 需求目标
- 移除训练记录页面中每组动作右侧的圆圈/勾选控件。
- 保留每个动作的名称、组数文本、日期与标题信息。
- 调整后页面仍然保持当前的信息层级与阅读节奏，不引入新的占位元素。

## 范围评估
- 本次需求属于 iOS 客户端历史页展示层调整。
- 不修改 `backend` 中的 Supabase Edge Function。
- 不修改 agent prompt、tool schema、训练计划数据结构与落库逻辑。

## 非目标
- 不调整聊天页和今日页中的组完成交互。
- 不修改训练完成状态的业务含义。
- 不新增“历史页完成计划动作”的替代交互。

## 验收标准
1. 历史页中选中某个计划日后，动作列表每组右侧不再展示空心圆或勾选圆。
2. 每组仍展示原有的重量/次数文案，例如“未设置 × 8”。
3. 页面其余模块，包括日历、已完成训练汇总、今日页、聊天页，不受影响。
4. 代码层面能通过回归校验，确保 `HistoryPlanDaySection` 不再渲染完成状态图标。
